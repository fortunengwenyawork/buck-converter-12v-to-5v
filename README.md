# 12V to 5V Buck Converter

## Overview

This project documents the design and simulation of a 12V to 5V DC-DC buck converter.

The objective is to:

- Design a switching regulator
- Simulate converter behavior in LTspice
- Analyze output voltage and inductor current
- Design a PCB in KiCad
- Generate manufacturing Gerber files

## Specifications

| Parameter | Value |
|------------|--------|
| Input Voltage | 12V |
| Output Voltage | 5V |
| Load Resistance | 2.5 Ω |
| Target Output Current | 2 A |
| Switching Frequency | 500 kHz |
